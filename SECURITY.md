# Security Policy

Found a security issue? Thanks for helping keep our project secure! Please report it responsibly so we can investigate and resolve it before any public disclosure.

## How to Report

Please do not open a public issue on GitHub.

Instead, send an email to **mohamed.haroka1@gmail.com** with the following details:

- What is the issue and what could happen if exploited?
- How can we see or trigger the problem?
- Has this already been shared or discussed publicly?
- Any code patch or ideas on how to resolve it (optional).

## What Happens Next

- We will acknowledge your email within **48 hours**.
- We will review the report and aim to share a fix or update within **7 days**.
- Please keep the issue private until we publish a fix.
- We are happy to thank and credit you in the release notes if you want!

## Scope

This policy applies to the codebase in this repository and its official releases.
